# Research SEO Playbook

This playbook turns the repo into the academic-facing search surface for the GareBear99 / TizWildin audio ecosystem.

## Primary keywords

- Python audio science
- Python scientific audio
- audio DSP Python
- music information retrieval Python
- MIR tools
- audio machine learning Python
- source separation Python
- citable audio software
- reproducible audio research
- open-source audio DSP
- JUCE plugin testing
- audio plugin validation

## Internal link strategy

Every research-facing project should link to:

- [awesome-python-audio-science](https://github.com/GareBear99/awesome-python-audio-science)
- [awesome-audio-plugins-dev](https://github.com/GareBear99/awesome-audio-plugins-dev)
- [awesome-audio-lists](https://github.com/GareBear99/awesome-audio-lists)
- [TizWildinEntertainmentHUB](https://github.com/GareBear99/TizWildinEntertainmentHUB)

## External authority strategy

- Submit compact entries to relevant awesome lists.
- Add DOI badges to key repos.
- Add `CITATION.cff` to key repos.
- Publish release notes with measured, verifiable claims.
- Avoid unverifiable “best in world” language in research pages.
- Use clear terms: experimental, prototype, source release candidate, validated release.
