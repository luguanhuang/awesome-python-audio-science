# Submission Guide

Use this format:

```markdown
- [Name](https://example.com/) - Short neutral description.
```

Good submissions are public, useful, maintained, and directly related to Python audio science or creator-audio automation.

For TizWildin / GareBear99 ecosystem additions, include the role: plugin, public router, deconstructed-loop surface, release vault, sample-pack hub, visualizer, or discovery list.
