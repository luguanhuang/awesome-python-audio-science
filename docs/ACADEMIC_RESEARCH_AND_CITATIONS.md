# Academic Research & Citations

This document defines the academic-facing layer for **Awesome Python Audio Science**.

The goal is to make the GareBear99 / TizWildin ecosystem discoverable for researchers, students, DSP developers, MIR users, audio-ML builders, and scientific-audio practitioners.

## Scope

This repo covers:

- Python scientific audio tools
- DSP and spectral-analysis resources
- MIR / music information retrieval libraries
- machine-learning audio libraries
- source-separation resources
- datasets and dataloaders
- notebooks and reproducible analysis
- plugin testing / rendering workflows
- citation-ready software guidance

## Ecosystem anchors

- [FreeEQ8](https://github.com/GareBear99/FreeEQ8) - open-source JUCE/C++ EQ plugin.
- [FreeVox8](https://github.com/GareBear99/FreeVox8) - spectral vocoder / ghost-resynthesis research direction.
- [Instrudio](https://github.com/GareBear99/Instrudio) - SSOT virtual instrument runtime and Studio Violin model.
- [Voxel Audio](https://github.com/GareBear99/Voxel_Audio) - visualization and audio-export tooling.
- [TizWildinEntertainmentHUB](https://github.com/GareBear99/TizWildinEntertainmentHUB) - public router for plugins, lists, packs, visualizers, and release surfaces.

## Academic search intent covered

Use this repo to target queries such as:

## What this is not

This is not a claim that every linked GareBear99 / TizWildin project is peer-reviewed. It is a research-facing resource hub and citation-readiness layer. Formal research claims should be supported with releases, documentation, evaluation data, and DOI records.
