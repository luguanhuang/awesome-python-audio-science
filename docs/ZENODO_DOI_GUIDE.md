# Zenodo DOI Guide for Audio Projects

A DOI makes a GitHub project easier to cite in papers, theses, reports, and educational references.

## Steps

1. Create or log into a Zenodo account.
2. Connect Zenodo to GitHub.
3. Enable the target repository in Zenodo.
4. Create a GitHub Release.
5. Zenodo archives the release and generates a DOI.
6. Add the DOI badge to the README.
7. Add the DOI to `CITATION.cff` and BibTeX.

## Best candidates

- [FreeEQ8](https://github.com/GareBear99/FreeEQ8) - first priority because it is a public audio-plugin proof anchor.
- [Instrudio](https://github.com/GareBear99/Instrudio) - strong candidate because of SSOT architecture and Studio Violin references.
- [FreeVox8](https://github.com/GareBear99/FreeVox8) - add DOI after the source/binary release is validated.

## Recommended DOI wording

Use a title that reads like software, not marketing:

`FreeEQ8: Open-source JUCE/C++ parametric equalizer plugin`

`Instrudio: Single-source-of-truth Web Audio virtual instrument runtime`

`FreeVox8: Spectral vocoder and ghost-resynthesis audio plugin`
