# Instrudio Research Bridge

[Instrudio](https://github.com/GareBear99/Instrudio) is the strongest research-architecture candidate in the ecosystem because it combines Web Audio synthesis, MIDI routing, live metrics, and single-source-of-truth instrument definitions.

## Research positioning

Instrudio can be positioned as:

- SSOT virtual instrument runtime
- Web Audio synthesis platform
- MIDI CC routing and note-mapping system
- plugin-bridge event protocol experiment
- preset/live-update propagation system
- physically informed Studio Violin implementation
- controllable synthesis and dataset-generation surface

## Studio Violin research angle

Studio Violin uses physically informed bowed-string ideas such as Helmholtz-style waveform synthesis, H2 correction, body resonance EQ, sympathetic resonance, nonlinear bow coupling, and runtime metrics.
