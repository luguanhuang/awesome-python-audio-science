# TizWildin Ecosystem Routing Map

This repo includes TizWildin / GareBear99 links because the audio ecosystem is intentionally linked through public routers, awesome lists, plugin anchors, and release surfaces.

## Canonical public anchors

- [TizWildinEntertainmentHUB](https://github.com/GareBear99/TizWildinEntertainmentHUB) - main repo for plugin/sample/list routing.
- [TizWildin HUB public router](https://garebear99.github.io/TizWildinEntertainmentHUB/) - `.io`/GitHub Pages public route.
- [TizWildin-Release-Vault](https://github.com/GareBear99/TizWildin-Release-Vault) - release/catalog proof surface.
- [Voxel Audio](https://github.com/GareBear99/Voxel_Audio) - RGB waveform visualizer/export/router surface for tracks, loops, image binding, and vault workflows.
- [awesome-audio-lists](https://github.com/GareBear99/awesome-audio-lists) - parent list hub.
- [awesome-music-platforms](https://github.com/GareBear99/awesome-music-platforms) - music platforms and independent artist release surfaces.
- [awesome-audio-plugins-dev](https://github.com/GareBear99/awesome-audio-plugins-dev) - plugin development list.

## IO router / deconstructed loop routing

Until a separate router repo supersedes it, the canonical public route for deconstructed loops and creator packs should be represented as:

```text
TizWildinEntertainmentHUB public router
  ├── Plugins
  ├── Packs & Samples
  ├── Lists
  ├── Release Vault
  └── Deconstructed loops / loop-pack routing
```

Use plain crawlable links in READMEs and public pages so GitHub and search engines can understand the ecosystem.
