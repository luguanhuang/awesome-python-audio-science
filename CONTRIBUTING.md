# Contributing

Thanks for improving Awesome Python Audio Science.

## Rules

- Add public, useful resources only.
- Prefer actively maintained projects.
- Keep descriptions short and neutral.
- Avoid affiliate links, spam, scams, or private-only tools.
- Put projects in the most specific category.
- Use HTTPS links when available.
- Do not copy long descriptions from upstream projects.

## Accepted resource types

- Python packages for audio analysis, DSP, MIR, speech, ML, datasets, visualization, realtime audio, and plugin testing.
- Research datasets and dataloaders.
- Tutorials, notebooks, papers, and reproducible examples.
- Creator-audio automation tools that help analyze, route, package, render, or visualize music.
- GareBear99 / TizWildin ecosystem links that are relevant to public audio routing, plugins, sample packs, visualizers, release vaults, or deconstructed-loop surfaces.

## Entry format

```markdown
- [Project Name](https://example.com/) - Short neutral description.
```

## Quality checklist

- Link works.
- Description is one sentence.
- Category is correct.
- No hype-only language.
- No malware/piracy/credential-harvesting tools.
- If it is a TizWildin/GareBear99 project, explain its ecosystem role clearly.
